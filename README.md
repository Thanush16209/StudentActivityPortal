# University Student Activity Management Portal

## Project Overview
A semantic and accessible HTML-based Student Activity Management Portal where students can view upcoming events and register for activities.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Semantic HTML structure
- Accessible navigation
- Student registration form
- Proper labels and input validation
- Keyboard-friendly navigation
- Responsive design
- JavaScript form submission
- Registration confirmation message
- Automatic form reset after submission

## Accessibility Testing
Tested using Google Lighthouse.

**Accessibility Score:** 100/100 (retain only if confirmed by your latest Lighthouse test).

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Form functionality
- `README.md` – Project documentation
- `audit.md` – Accessibility audit report

## How to Run
Open `index.html` in a web browser.

# Student Activity Management Portal

## Project Overview
A semantic and accessible HTML-based Student Activity Management Portal designed to manage student activities and registrations.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Semantic HTML structure
- Accessible navigation
- Student registration form
- Proper labels and input validation
- Keyboard-friendly navigation
- Responsive design

## Accessibility Testing
Tested using Google Lighthouse.

**Accessibility Score: 100/100**

## Project Files
- `index.html` – Website structure
- `style.css` – Styling
- `script.js` – JavaScript functionality
- `audit.md` – Accessibility audit report

## How to Run
Open `index.html` in a web browser.
